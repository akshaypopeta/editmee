How to Use the Rotate PDF Tool

  1. Click the Choose PDF button.
  2. Select the PDF document you want to rotate.
  3. Choose the pages you want to rotate.
  4. Select the rotation angle (90°, 180°, or 270°).
  5. Click the Rotate PDF button.
  6. Download the rotated PDF file.
